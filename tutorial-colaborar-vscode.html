MediFlow — Guía de colaboración

Contribuir al proyecto
desde Visual Studio Code

Paso a paso para nuevos colaboradores · Sin usar la terminal

Proyecto: github.com/thelion182/mediflow · Mayo 2026

1

Instalar lo necesario

Instalar estos tres programas en orden y reiniciar la computadora cuando terminen:

  1. Git → https://git-scm.com/downloads (opciones por defecto)
  2. Node.js LTS → https://nodejs.org
  3. Visual Studio Code → https://code.visualstudio.com
2

Instalar la extensión de GitHub en VS Code

  1. Abrir VS Code
  2. Clic en el ícono de extensiones en la barra izquierda (parece 4 cuadraditos)
  3. Buscar "GitHub Pull Requests"
  4. Instalar la extensión oficial de GitHub (autor: GitHub)
3

Conectar VS Code con la cuenta de GitHub

  1. En VS Code, clic en el ícono de cuentas (abajo a la izquierda, parece una persona)
  2. Clic en "Sign in with GitHub"
  3. Se abre el navegador → iniciar sesión en GitHub → clic en Authorize
  4. Volver a VS Code — ya queda conectado, no necesita tokens ni contraseñas
4

Aceptar la invitación al repositorio

  1. Revisar el email de GitHub con asunto: "[thelion182] invited you to collaborate"
  2. Hacer clic en el botón verde Accept invitation
  3. Si no llega el mail, buscar en spam o entrar directamente a:
https://github.com/thelion182/mediflow/invitations
5

Clonar el proyecto desde VS Code

  1. En VS Code, abrir la paleta de comandos: Ctrl + Shift + P
  2. Escribir Git: Clone y seleccionarlo
  3. Pegar la URL del repositorio:
https://github.com/thelion182/mediflow
  1. Elegir la carpeta donde guardar el proyecto (ej: C:\Proyectos)
  2. Cuando VS Code pregunte "¿Abrir el repositorio clonado?" → clic en Abrir
6

Instalar dependencias y levantar el proyecto

  1. Abrir la terminal integrada de VS Code: Ctrl + ` (tecla del acento grave, arriba del Tab)
  2. Ejecutar:
npm install
  1. Cuando termine, ejecutar:
npm run dev
  1. Hacer clic en el link http://localhost:5173 que aparece — se abre MediFlow en el navegador
7

Crear su propia rama de trabajo

⚠ Importante: nunca modificar main directamente. Siempre trabajar en una rama propia.

En VS Code esto es muy visual:

  1. Mirar la barra de estado inferior — dice main a la izquierda
  2. Hacer clic en ese main
  3. Seleccionar "+ Create new branch..."
  4. Escribir el nombre de la rama, por ejemplo: feature/jp-parte-diario
  5. Presionar Enter

La barra inferior ahora muestra el nombre de la nueva rama. ✓

8

Editar archivos y guardar cambios (commit)

  1. Editar los archivos necesarios desde el explorador de VS Code (barra izquierda)
  2. Ir al ícono de control de código fuente: Ctrl + Shift + G
  3. Ver todos los archivos modificados en la lista
  4. Hacer clic en + al lado de cada archivo para prepararlo (o el + grande para preparar todos)
  5. Escribir un mensaje descriptivo en el campo de texto, por ejemplo:
feat: agregar columna sector en parte diario
  1. Clic en el botón azul "Commit" (o Ctrl + Enter)
9

Subir los cambios a GitHub (push)

  1. En el panel de control de código fuente, clic en "Publish Branch" (la primera vez) o "Sync Changes" (las siguientes)
  2. Como ya inició sesión con GitHub en el Paso 3, sube automáticamente sin pedir contraseña

También aparece un ícono de nube ☁ en la barra inferior para hacer push rápido.

10

Pedir que integren los cambios (Pull Request)

  1. Ir a https://github.com/thelion182/mediflow en el navegador
  2. Aparece un banner amarillo "Compare & pull request" → hacer clic
  3. Escribir título y descripción de qué cambió y por qué
  4. Clic en "Create pull request"

Leon lo revisa y lo aprueba desde GitHub cuando esté listo.

Si algo no funciona

Problemas comunes y solución rápida

  • No aparece "Publish Branch" → cerrar y reabrir VS Code
  • Pide usuario y contraseña → repetir el Paso 3 (Sign in with GitHub)
  • Error al hacer npm install → verificar que Node.js está instalado (node --version en terminal)
  • Conflicto de merge → avisarle a Leon antes de intentar resolverlo solo
